## Getting Started

### Creating Your Account

1. Navigate to [app.caseradar.com](https://app.caseradar.com)
2. Click **Sign Up**
3. Enter your email and create a password, or sign in with Google
4. Verify your email address
5. Complete your profile setup

### Joining an Organization

If your law firm already uses CaseRadar:

1. Ask your administrator for an invitation
2. Click the invitation link in your email
3. Sign in or create an account
4. You'll automatically be added to your organization

### Choosing a Plan

CaseRadar offers three tiers:

- **Free**: Perfect for initial exploration (100 searches/month, 5 saved searches)
- **Professional**: For active case research ($99/month, unlimited searches, document generation)
- **Enterprise**: For firms with multiple attorneys (custom pricing, all features, priority support)

## Searching Complaints

### Basic Search

1. Click the **Search** tab or use the search bar
2. Enter keywords (e.g., "brake failure", "transmission")
3. Press Enter or click **Search**

### Advanced Filters

Refine your search using filters:

| Filter | Description | Example |
|--------|-------------|---------|
| Make | Vehicle manufacturer | Toyota, Ford, Honda |
| Model | Specific model | Camry, F-150, Civic |
| Year Range | Model years | 2018-2023 |
| Component | Vehicle component | Brakes, Airbags, Steering |
| State | Incident location | California, Texas |
| Date Range | When complaint filed | Last 90 days |
| Severity | Injury/crash involvement | Crashes only |

### Semantic Search

CaseRadar uses AI to understand the meaning of your search, not just keywords:

- "sudden acceleration while parking" finds complaints about unintended acceleration
- "car caught fire while parked" finds fire-related incidents even if described differently
- "steering wheel locked up" finds power steering and steering column issues

### Saving Searches

1. Perform a search with your desired filters
2. Click **Save Search**
3. Name your search (e.g., "Toyota Brake Issues 2020+")
4. Optionally set up an alert for new matches
5. Access saved searches from your dashboard

### Exporting Results

1. Perform a search
2. Click **Export**
3. Choose format:
   - **CSV**: For spreadsheet analysis
   - **PDF**: For reports and documentation
   - **JSON**: For technical integrations

## Understanding Patterns

### What Are Patterns?

CaseRadar automatically groups similar complaints into patterns using AI analysis. A pattern represents:

- Multiple complaints about the same issue
- Affecting the same or similar vehicles
- With similar descriptions and outcomes

### Pattern List View

The Patterns page shows:

- **Pattern Name**: AI-generated description (e.g., "2019-2021 Honda CR-V Brake Pedal Sinking")
- **Complaint Count**: Number of grouped complaints
- **Severity Score**: 1-10 based on injuries, deaths, crashes
- **Trend**: Rising, stable, or declining
- **Vehicles Affected**: Make/model/year combinations

### Pattern Detail View

Click a pattern to see:

- **Overview**: Summary of the issue
- **Timeline**: When complaints were filed
- **Geographic Distribution**: Where incidents occurred
- **Related Complaints**: All grouped complaints
- **Similar Patterns**: Related issues worth investigating

### Pattern Metrics

| Metric | Description |
|--------|-------------|
| Severity Score | Weighted score (deaths=10, injuries=5, crashes=3, fires=3) |
| Growth Rate | Week-over-week change in complaint volume |
| Geographic Spread | Number of states with complaints |
| Time Span | Duration from first to most recent complaint |

## Setting Up Alerts

### Creating an Alert

1. Go to **Alerts** > **New Alert**
2. Configure alert criteria:
   - **Search Query**: Keywords or saved search
   - **Vehicle Filters**: Make, model, year range
   - **Severity Threshold**: Minimum severity to trigger
   - **Frequency**: Immediate, daily digest, or weekly
3. Choose notification method:
   - Email
   - In-app notification
   - Both
4. Click **Create Alert**

### Alert Types

| Type | Description | Best For |
|------|-------------|----------|
| New Complaints | Alert when new complaints match criteria | Tracking specific vehicles |
| Pattern Detection | Alert when a new pattern is detected | Discovering emerging issues |
| Severity Spike | Alert when pattern severity increases | Monitoring high-risk patterns |
| Threshold | Alert when complaint count exceeds limit | Volume monitoring |

### Managing Alerts

- **Pause**: Temporarily disable without deleting
- **Edit**: Modify criteria or notification settings
- **Delete**: Permanently remove the alert
- **Test**: Send a test notification to verify setup

### Alert Best Practices

1. **Start Broad, Refine Later**: Create a general alert, then narrow based on results
2. **Use Daily Digests**: Avoid alert fatigue with summary emails
3. **Set Severity Thresholds**: Filter out minor issues
4. **Review Regularly**: Disable alerts that no longer serve your needs

## Generating Documents

### Document Types

CaseRadar generates several document types:

| Document | Description | Use Case |
|----------|-------------|----------|
| Formal Complaint | Legal complaint ready for filing | Initiating lawsuits |
| Pattern Report | Detailed analysis of a pattern | Client presentations |
| Complaint Summary | Brief overview of an issue | Initial case evaluation |
| Evidence Package | Compiled complaints with citations | Discovery preparation |

### Generating a Document

1. Navigate to a pattern or complaint
2. Click **Generate Document**
3. Select document type
4. Configure options:
   - **Jurisdiction**: State/federal court
   - **Plaintiff Information**: Your client details
   - **Defendant(s)**: Manufacturer, dealer, etc.
   - **Causes of Action**: Negligence, breach of warranty, etc.
5. Click **Generate**
6. Review and download

### Document Templates

Enterprise users can create custom templates:

1. Go to **Settings** > **Document Templates**
2. Click **New Template**
3. Upload your firm's template (DOCX format)
4. Map CaseRadar fields to template placeholders
5. Save and use for future document generation

### Editing Documents

Generated documents are starting points:

1. Download in DOCX format
2. Open in Microsoft Word or Google Docs
3. Review and customize content
4. Add case-specific details
5. Have legal review before filing

## Tips and Best Practices

### Effective Search Strategies

1. **Use Natural Language**: "brake pedal goes to floor" works better than "brake fail"
2. **Combine Filters**: Narrow by make + year range + component
3. **Check Similar Models**: Issues often affect related vehicles
4. **Review Time Periods**: Problems may be seasonal or model-year specific

### Pattern Analysis Tips

1. **Look for Clusters**: Multiple low-severity complaints may indicate a larger issue
2. **Track Geographic Patterns**: Regional issues may indicate manufacturing batches
3. **Monitor Trends**: Rising patterns deserve attention even at low volumes
4. **Compare to Recalls**: Check if patterns align with announced recalls

### Document Generation Tips

1. **Start with Pattern Reports**: Understand the issue before drafting complaints
2. **Verify Data**: Always verify key facts in original NHTSA records
3. **Customize Thoroughly**: Generated documents need attorney review
4. **Keep Records**: Export and archive generated documents

### Organization Tips

1. **Use Folders**: Organize saved searches by case or client
2. **Share Searches**: Collaborate with team members on research
3. **Regular Reviews**: Weekly pattern review catches emerging issues
4. **Document Everything**: Generate reports to document your research process

## Glossary

| Term | Definition |
|------|------------|
| Complaint | An individual report filed with NHTSA |
| Component | Vehicle part category (e.g., Brakes, Airbags) |
| Pattern | A group of similar complaints identified by AI |
| Severity Score | Weighted measure of complaint seriousness |
| ODI Number | NHTSA's unique complaint identifier |
| Recall | Official manufacturer recall announced by NHTSA |
| Trend | Direction of complaint volume over time |
